# Contributing

Thanks for your interest in contributing to Roblox Dev Toolkit.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test your changes in Roblox Studio when applicable.
5. Open a pull request explaining what you changed.

## Guidelines

* Write clear Luau code.
* Keep modules focused and reusable.
* Avoid unnecessary dependencies.
* Update documentation when behavior changes.
* Test changes before submitting a pull request.

## Bug Reports

When reporting a bug, include:

* What happened
* What you expected to happen
* Steps to reproduce the problem
* Relevant code or error messages

## Feature Requests

Explain the problem the feature would solve and provide an example of how you would use it.
